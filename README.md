RunState is a running app I'm building.

Most running apps tell you what you did — distance, pace, time. RunState is about what the run meant. How you felt going into it, what it asked of you, and what you came away with.

Music is a big part of that. The app pays attention to what you were listening to and how the run actually went, and connects the two.

What you're looking at

A preview of the run history screen. Every row is a run.

Tap one and it opens up. You'll see the details of that run and a short written reflection — and the app reads it aloud in a natural voice.

Everything here is example data. This is a design preview, not the working app.

The actual app

The working version is real software that logs runs, remembers them, notices patterns as they build up over time, and writes those reflections. It runs on a computer for now — these designs are for the phone version it's becoming.
