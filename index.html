RUNSTATE DESIGN PREVIEWS

What the run meant,
not just what it recorded.

RunState is a running app I'm building. Most running apps tell you what you did — distance, pace, time. This one is about how the run felt going in, what it asked of you, and what you took away. Music is a big part of that.

SCREEN ONE
Start a run →
Choose an energy level, press Start — then tap Pause, and hold Stop to end.
SCREEN TWO
Log history →
Tap any run to open it. It reads its own reflection out loud.
These are interactive design prototypes, not the working app. Everything shown uses example data, and some elements are visual only. Both screens are early versions and will be replaced as the design continues.
Best on a phone. The actual application lives at github.com/Manley-codes/RunState.
